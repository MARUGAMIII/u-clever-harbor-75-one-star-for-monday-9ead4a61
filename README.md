A one-line, one-star review of Monday written as if Monday were a restaurant, for make.fun's "One Star for Monday" bounty ($2 in USDC). The diner sat down for the weekend and got served Monday instead: the waiter spilled the coffee, the alarm never rang, and the bill turned out to be a 9am meeting.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
